# Varando do Esperto — Login

Página de login responsiva para celular e computador.

## Publicação
O GitHub Pages é publicado pelo workflow em `.github/workflows/pages.yml`.

Antes da publicação, confirme em **Settings → Pages** que a fonte está configurada como **GitHub Actions**.

## Autenticação
Para habilitar login e recuperação de senha, configure a URL e a chave pública do projeto Supabase no `index.html`.
